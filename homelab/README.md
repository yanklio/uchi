# Homelab

Local homelab services live here.

## Layout

- `apps/`: Podman Compose app definitions.
- `scripts/`: `homelab.sh` and `homelab.py` container lifecycle CLI.
- `.env`: generated by Ansible from `ansible/templates/homelab.env.j2` and ignored by git.

## Commands

```bash
./scripts/containers.sh start
./scripts/containers.sh stop
./scripts/containers.sh restart
./scripts/containers.sh status
./scripts/containers.sh doctor
```

The safe defaults are Tailscale-only access, localhost app binding, and DHCP disabled. Server setup does not start containers.
